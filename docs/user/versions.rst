Board Versions
##############

There are currently two production versions of the LimeSDR PCIe board: v1.2 and v1.3.

v1.2 and v1.3 boards are supported by the same software. New hardware features added in each board version are listed in Table 1.

.. list-table:: Table 1. New features in each board version
   :header-rows: 1
   :stub-columns: 1

   * - Version
     - New features
   * - v1.3
     - 125 MHz LVDS oscillator (XO6) connected to the FPGA transceiver reference clock input.
   * - v1.2
     - Initial version.
