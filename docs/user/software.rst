Software
########

LimeSDR PCIe is supported by the :external+suite:ref:`Lime Suite Classic software <index:introduction>`, which provides drivers, command line utilities, plug-ins for popular ecosystem applications, and a graphical user interface (GUI) application for advanced engineering/debugging tasks.

.. note::
   LimeSDR PCIe hardware is not supported by the classic Lime Suite NG software.

For a guide to getting up and running with Lime Suite Classic, please refer to the :external+quickstart:ref:`SDR Quick Start <index:introduction>`.
