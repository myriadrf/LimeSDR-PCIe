RF Network Control
##################

LimeSDR PCIe v1.3 board contains RF loopback switches (IC4, IC5, IC6, IC7) for LMS7002M which are controlled from FPGA. By using loopback switches RF path TX1_2 can be connected to RX1_H and TX2_2 to RX2_H.

.. table:: Table 3. RF path control signals
        
  +-------------------+---------------------------+--------------+------------------+
  | **Loopback path** | **Schematic signal name** | **FPGA pin** | **I/O standard** |
  +===================+===========================+==============+==================+
  | TX1_2             | TX1_2_LB_L                | A22          | 3.3V             |
  |                   +---------------------------+--------------+------------------+
  |                   | TX1_2_LB_H                | A21          | 3.3V             |
  |                   +---------------------------+--------------+------------------+
  |                   | TX1_2_LB_SH               | B20          | 3.3V             |
  +-------------------+---------------------------+--------------+------------------+
  | TX2_2             | TX2_2_LB_L                | B22          | 3.3V             |
  |                   +---------------------------+--------------+------------------+
  |                   | TX2_2_LB_H                | B21          | 3.3V             |
  |                   +---------------------------+--------------+------------------+
  |                   | TX2_2_LB_SH               | C22          | 3.3V             |
  +-------------------+---------------------------+--------------+------------------+
