Overview
########

The heart of the LimeSDR PCIe board is Altera Cyclone IV (P4CGX30CF23C7N) FPGA. Its main function is to transfer digital data between LMS7002M RF transceiver and the PC through a PCI Express x4 connector. The block diagram for LimeSDR USB board is presented in the Figure 3.

.. figure:: /images/LimeSDR-PCIe_v1.3_diagrams_bd.png
  :width: 600

  Figure 3: LimeSDR PCIe v1.3 board block diagram

This section contains component location description on the board. LimeSDR PCIe v1.3 board picture with highlighted connectors and main components are presented in Figure 4 and Figure 5, respectively.

.. figure:: /images/LimeSDR-PCIe_v1.3_components_top.png
  :width: 600

  Figure 4: LimeSDR PCIe v1.3 board top connectors and main components

.. figure:: /images/LimeSDR-PCIe_v1.3_components_bot.png
  :width: 600

  Figure 5: LimeSDR PCIe v1.3 board bottom connectors and main components
